Baseline pilot W26 moves to W27 after CR-P01. Expanded release moves from W28 to W29. Final closure remains W32 using the planned transition window. The baseline is retained alongside the forecast in the schedule register; the forecast change is not hidden.

The gating dependency path is approved rules → design → build → reconciled migration → UAT and operational gate → pilot → expansion review → expansion → handover. Training and runbook preparation run in parallel, but cannot substitute for migration acceptance. No claim of a fully resource-levelled critical-path calculation is made by the milestone register.
